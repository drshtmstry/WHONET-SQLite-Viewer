Bulk Data Corrections
Apply standardized quality fixes across all database records
SPEC_NUM → Uppercase
Normalize all specimen numbers to uppercase to prevent case-sensitive duplicate mismatches.
UPDATE Isolates SET SPEC_NUM = UPPER(SPEC_NUM)
PATIENT_ID → Uppercase
Normalize Patient IDs to uppercase for consistent lookups and deduplication.
UPDATE Isolates SET PATIENT_ID = UPPER(PATIENT_ID)
Trim Whitespace
Remove leading and trailing spaces from SPEC_NUM, PATIENT_ID, WARD, and DEPARTMENT (plus FULL_NAME when stored as a plain column).
UPDATE Isolates SET field = TRIM(field)
ORGANISM → Lowercase
Standardize organism codes to lowercase as used in official WHONET code lists.
UPDATE Isolates SET ORGANISM = LOWER(ORGANISM)
